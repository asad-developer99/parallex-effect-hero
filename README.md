# Mostar — Cinematic Scroll Story

A cinematic, three-screen scroll-driven storytelling page showcasing the city of Mostar, Bosnia and Herzegovina — built with plain HTML, CSS, and JavaScript, no framework or build step.

## Features
- Multi-layer parallax scroll effect (sky, bridge, bazaar layers moving at different speeds)
- Scroll-scrubbed CSS custom properties driving opacity, blur, position, and scale transitions
- Interactive "sights" slider showcasing landmarks (e.g. Stari Most / Old Bridge)
- Language switcher and sectioned navigation (Intro, Bridge, Bazaar, Routes)

## Tech Stack
Vanilla HTML · CSS · JavaScript (no build tools required)

## Getting Started
Just open `index.html` in a browser, or serve the folder with any static file server:
```bash
npx serve .
```
